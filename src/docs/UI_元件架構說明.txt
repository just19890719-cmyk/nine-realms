《九界鐵匠》v3.10 UI 元件架構說明（給美術整合用）
日期：2026-10-20

======================================================================
一、一句話說明
======================================================================
全遊戲的按鈕、面板、卡片、彈窗、導航列都已經掛上共用的「ui- 元件類別」。
美術素材交付後，只要改 skin.js 這一個檔案，再執行 python3 build.py，
所有使用該元件的畫面就會一起換上新外觀。遊戲程式與 style.css 都不用改。

目前 skin.js 每個槽位都是 null，所以外觀和 v3.9 完全一樣。

======================================================================
二、檔案位置
======================================================================
 skin.js              UI 皮膚設定（唯一需要改的檔案）
 style.css            原本的樣式，已整理分區；最後兩段是皮膚系統與元件總覽頁
 game.js              皮膚引擎：SKIN_SLOTS（槽位表）、skinCss()、applySkin()、ic()、uiGallery()
 build.py             建置：把 style.css、skin.js、game.js、tests.js 嵌入 pub/index.html
 pub/index.html       建置後的遊戲（直接用瀏覽器開）
 pub/art/             美術素材資料夾；建議新 UI 素材放 pub/art/ui/
 qa/                  驗證工具（外觀前後比對、皮膚試套測試）

======================================================================
五、怎麼填（範例）
======================================================================
 9-slice 按鈕（可任意伸縮，四角不變形）：
   'btn-primary': {src:'art/ui/ui_btn_primary_normal.webp', slice:[40,70,40,70], border:[12,24,12,24]},
   'btn-primary:pressed': {src:'art/ui/ui_btn_primary_pressed.webp'},
   'btn-primary:disabled': {src:'art/ui/ui_btn_primary_disabled.webp'},

 整張背景（不伸縮邊框，例如頂部列、頁面背景）：
   'topbar': {src:'art/ui/ui_topbar.webp', mode:'bg'},

 參數：
   src      圖片路徑（PNG 或 WebP，真透明背景）
   mode     '9slice'（預設）或 'bg'
   slice    四邊不可拉伸的寬度（原圖像素），順序：上、右、下、左
   border   畫面上四邊框的顯示寬度（px），順序同上；省略＝slice 的 1/3
   repeat   'stretch'（拉伸，預設）或 'round'（重複花紋）
   fill     true（預設）中間也畫；false 只畫外框
   shadow   false（預設）拿掉原本 CSS 陰影；true 保留
   css      額外 CSS，例如 'padding:4px 18px;color:#ffe9b8'
 狀態槽位只要給 src，其他參數沿用一般狀態。

 介面圖示（UI_ICON，填圖片路徑；null＝用原本的文字符號）：
   info（ⓘ）、arrow-next（➜）、arrow-left（‹）、arrow-right（›）、clear（✕）、sound-on（🔊）、sound-off（🔇）

======================================================================
六、素材規格建議
======================================================================
 格式：WebP（優先）或 PNG，必須是真透明背景（不能有白底、灰底、黑底或棋盤格）。
 解析度：畫成實際顯示尺寸的 3 倍。例：按鈕顯示高 44px → 素材高約 132px。
 9-slice 素材：四角放花紋，四邊中段與中央要能拉伸或重複而不破圖；中央不要放文字。
 每個狀態一張獨立圖片，尺寸與四角位置要一致（一般／按下／停用）。
 建議檔名：ui_<槽位>_<狀態>.webp，例：ui_btn_primary_normal.webp、ui_panel.webp、ui_navtab_on.webp。

======================================================================
七、驗收方式
======================================================================
 1. 開啟 pub/index.html#dev-ui，會直接打開「開發工具 → UI 元件」總覽頁：
    所有按鈕（一般／按下／停用）、分頁、面板、卡片、標籤、進度條、彈窗、提示訊息、圖示、
    24 個皮膚槽位的套用狀態，都在同一頁。
 2. 總覽頁的「9-slice 試套」按鈕：用現有的木紋圖暫時套到主要按鈕，確認 9-slice 引擎正常；
    再按一次還原。這只是測試，不會寫進存檔。
 3. 自動檢查：
    node qa/skin_test.js                         皮膚試套、狀態槽位、還原、320/390/430 溢出
    node qa/capture.js qa/新資料夾               擷取 35 個畫面 × 3 種寬度的樣式與截圖
    python3 qa/diff.py qa/base qa/新資料夾 320,390,430 50   和 v3.9 原外觀逐元素比對
